# Garsooon-Red-Bot-Cogs

Cogs for [Red-DiscordBot](https://github.com/Cog-Creators/Red-DiscordBot).

| Cog | Description |
| --- | --- |
| `rmcstats` | RetroMC player stats and leaderboards |
| `rmcwiki` | RetroMC wiki lookup |
| `pingprotect` | Ping protection |

## Install

```
[p]repo add Garsooon-Red-Bot-Cogs https://github.com/Garsooon/Garsooon-Red-Bot-Cogs
[p]cog install Garsooon-Red-Bot-Cogs <cog>
```
